# Запуск SIGame на личном ПК с доступом из интернета

Этот вариант подходит, если игра должна работать во время мероприятия, а компьютер ведущего может оставаться включённым. Один запущенный процесс может обслуживать несколько комнат одновременно.

## 1. Установка Node.js

Установите Node.js 22 LTS с официального сайта:

https://nodejs.org/

Проверьте установку:

```bash
node --version
npm --version
```

Версия Node должна быть 22 или новее.

## 2. Запуск проекта

Распакуйте `si-local-pc-ready.zip` или исходный архив. Откройте терминал в папке, где лежит `package.json`.

Выполните один раз:

```bash
npm ci
```

Затем соберите и запустите production-версию:

```bash
npm run build
npm start
```

Не закрывайте это окно терминала. На компьютере ведущего сайт будет доступен по адресу:

```text
http://localhost:5174
```

Если Windows спросит разрешение для Node.js в брандмауэре, разрешите доступ хотя бы для частных сетей.

## 3. Доступ с устройств в той же Wi‑Fi сети

Узнайте локальный IP компьютера:

- Windows: выполните `ipconfig` и найдите IPv4-адрес, например `192.168.1.25`.
- macOS/Linux: выполните `ifconfig` или `ip addr`.

На другом устройстве в той же сети откройте:

```text
http://192.168.1.25:5174
```

## 4. Доступ из интернета через LocalTunnel

LocalTunnel не требует проброса портов на роутере. Он использует Node.js, который уже установлен для запуска игры.

Оставьте первое окно с `npm start` открытым. Во втором окне терминала выполните:

```bash
npx localtunnel --port 5174
```

Если появится вопрос об установке пакета, подтвердите его. В терминале появится адрес примерно такого вида:

```text
https://some-name.loca.lt
```

Откройте эту ссылку сами как ведущий и отправьте её игрокам. В блоке «Как войти» автоматически будет отображаться правильная публичная ссылка.

Для пака размером 250 МБ и больше не загружайте файл через публичную ссылку `loca.lt`: бесплатный туннель добавляет задержку и может оборвать длинную передачу. Откройте ведущему отдельную локальную вкладку `http://localhost:5174`, создайте комнату и загрузите пак там. Игроки при этом могут заходить через публичную ссылку туннеля в ту же комнату.

Если ведущий находится в другом месте, он может открыть публичную ссылку туннеля, выбрать роль «Ведущий», ввести заранее выбранный 4-символьный код и нажать «Создать комнату и войти». Серверный ПК создаст комнату при первом входе ведущего. Игроки затем заходят по той же публичной ссылке и этому коду.

Окно LocalTunnel нужно оставить открытым. Ссылка работает, пока работает этот процесс, и может измениться после перезапуска. Остановить туннель можно сочетанием `Ctrl+C`.

Официальная документация команды: https://github.com/localtunnel/localtunnel

## 5. Запасной вариант — Pinggy через SSH

Если `loca.lt` не открывается из вашей сети, можно использовать Pinggy. На Windows 10/11, macOS и большинстве Linux уже есть SSH-клиент.

В отдельном окне терминала выполните:

```bash
ssh -p 443 -R0:127.0.0.1:5174 free.pinggy.io
```

На Windows используйте именно `127.0.0.1`, а не `localhost`. Если SSH спросит подтверждение fingerprint, ответьте `yes`. Если попросит пароль, оставьте поле пустым и нажмите Enter.

В выводе появится публичный HTTPS-адрес. Передайте его игрокам. Бесплатный Pinggy ограничивает длительность туннеля; после остановки или истечения времени адрес нужно получить заново.

Официальный сайт и инструкция: https://pinggy.io/

## 6. Постоянный адрес

LocalTunnel и бесплатный Pinggy подходят для проведения отдельной игры, но их адреса временные. Для постоянной ссылки лучше разместить проект на Railway или на собственном VPS. При этом для текущей версии нужно оставить одну реплику сервера, потому что комнаты и загруженный `.siq` хранятся в памяти одного процесса.

## Важные ограничения

Компьютер должен оставаться включённым и не переходить в сон. Если компьютер выключится, потеряет интернет или будут закрыты окна `npm start` и туннеля, сайт станет недоступен.

Не делайте проброс порта `5174` на роутере без необходимости. Туннель не требует открывать входящий порт.

Любой человек, получивший публичную ссылку, сможет открыть сайт. Пароль комнаты состоит всего из 4 символов, поэтому не публикуйте ссылки и пароли открыто. После игры остановите туннель сочетанием `Ctrl+C`.

Все комнаты, игроки, очки и загруженный `.siq` хранятся в памяти текущего процесса. После перезапуска компьютера или приложения нужно создать комнаты заново и повторно загрузить пак.

## Ежедневный порядок запуска

Окно 1:

```bash
npm start
```

Окно 2:

```bash
npx localtunnel --port 5174
```

Если LocalTunnel недоступен, вместо второй команды используйте:

```bash
ssh -p 443 -R0:127.0.0.1:5174 free.pinggy.io
```
