# Развёртывание SIGame на Railway

Проект подготовлен для запуска одним production-контейнером. В корне есть `Dockerfile`: Railway обнаружит его автоматически, соберёт клиент и сервер, а затем запустит скомпилированный Node-сервер.

## Через GitHub и Dashboard

1. Создайте репозиторий на GitHub и загрузите **содержимое папки `si`** в корень репозитория.
2. В Railway выберите **New Project → Deploy from GitHub Repo** и укажите этот репозиторий.
3. Дождитесь сборки. Переменные `PORT` и `HOST` вручную задавать не нужно: Railway сам передаёт `PORT`, приложение слушает `0.0.0.0`.
4. В настройках сервиса откройте **Networking → Public Networking → Generate Domain**. Получившийся HTTPS-адрес и есть ссылка, которую ведущий показывает игрокам.
5. В настройках сервиса укажите healthcheck path `/health`. Endpoint отвечает `200 OK`, когда сервер запущен.

Railway поддерживает WebSocket-соединения через HTTP/1.1, поэтому Socket.IO в этой конфигурации работает через тот же публичный домен. Не добавляйте отдельный frontend-сервис и не запускайте несколько реплик: комнаты, подключённые клиенты и очки хранятся в памяти одного Node-процесса. Сам `.siq` теперь сохраняется во временное дисковое хранилище и медиа читаются с диска по запросу, поэтому большой архив не должен полностью занимать RAM.

## Через Railway CLI

В корне проекта:

```bash
railway login
railway init
railway up
```

После деплоя сгенерируйте домен в настройках сервиса или командой `railway domain`.

## Ограничения этой версии

Состояние игры не является постоянным. После перезапуска, redeploy или остановки сервиса нужно создать комнату заново и снова загрузить `.siq`-пак. Это сделано намеренно: для игры с Socket.IO нужен один процесс, а подключение базы данных для временной игровой сессии здесь не требуется.

Размер пакета по умолчанию ограничен переменной `PACK_UPLOAD_LIMIT_MB=300`. Сервер больше не буферизует весь upload и не держит все медиа в RAM, но архив должен помещаться во временный диск вместе с распакованным содержимым. Если распакованный пакет превышает доступный диск Railway, загрузка всё равно не завершится; для такого пака нужен сервис с большим диском или внешнее объектное хранилище.

На странице Railway сейчас указано, что Free начинается с 30-дневного пробного периода с кредитами, после которого действует лимит $1 в месяц; ресурсы и условия тарифа могут изменяться. Для одной небольшой игры текущего контейнера достаточно, но Railway не следует воспринимать как гарантированно бесплатный бессрочный хостинг.
